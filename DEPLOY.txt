FINCLOUD - DEPLOY (hosting + Firestore rules)

One-time:
  npm install -g firebase-tools
  firebase login

Every deploy (from this folder):
  firebase deploy --only hosting,firestore

IMPORTANT: deploy "firestore" too, not just hosting. The new loginEvents
rules are required or login tracking is silently rejected.
